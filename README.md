# CGPU Monitor 🖥️⚡ `v1.1.0`

macOS 실시간 시스템 모니터링 데스크톱 위젯 & 메뉴바 애플리케이션 (SwiftUI + AppKit)

Apple Silicon 및 Intel Mac에서 **CPU, GPU, RAM, SSD, Network, Battery** 상태를 바탕화면에 세련된 글래스모피즘(Glassmorphism) 반투명 위젯으로 실시간(1초 주기) 표시합니다.

---

## 주요 기능

1. **CPU 모니터링**:
   - 실시간 전체 CPU 사용률 (%)
   - 활성 코어 수 및 프로세서 모델명
   - 실시간 스파크라인 추이 그래프
2. **GPU 모니터링**:
   - Apple Silicon GPU 가속기 실시간 점유율 (%)
   - GPU 사용량 스파크라인 그래프
3. **RAM 모니터링**:
   - 실시간 메모리 사용률 (%) 및 실제 사용량 / 총 용량 (GB)
   - 앱 메모리, 와이어드 메모리, 압축 메모리 정밀 계산
4. **SSD (디스크) 모니터링**:
   - 메인 스토리지(Macintosh HD) 점유율 (%)
   - 남은 여유 용량(GB) 및 전체 디스크 용량(GB)
5. **네트워크 & 배터리 모니터링**:
   - 초당 실시간 다운로드/업로드 속도 (MB/s, KB/s)
   - 배터리 잔여량 및 전원 어댑터 연결/충전 상태
6. **3단계 접기 모드 (Window Sizing)**:
   - **보통 (Standard)**: 2열 상세 대시보드 + 코어 수/모델명/여유 용량 + 20초 실시간 스파크라인 그래프
   - **작게 (Compact)**: 미니 원형(Ring) 게이지로 깔끔하게 축소
   - **완전 한줄 (Minimal, 28pt)**: macOS 표준 창의 제목표시줄(Titlebar) 높이(28pt)로 한 줄에 메트릭을 보여주는 초슬림 바 위젯! (텍스트 잘림 없는 가변 너비 지원)
7. **마우스 호버(Hover) 상세 센서 팝오버**:
   - `CPU`, `GPU`, `RAM`, `SSD`, `NET`, `BAT` 위에 마우스를 슥 올리면(Hover) **온도(°C), 소비 전력(W), 팬 속도(RPM), P/E 코어 분할, 스왑 메모리, APFS 포맷, 네트워크 통계** 등의 풀스펙 팝오버 카드가 즉시 펼쳐집니다.
8. **표시 항목 맞춤 설정 (Metrics Config)**:
   - 위젯 헤더의 **설정(⚙️) 아이콘** 또는 상단 메뉴바의 **`Displayed Metrics`** 서브메뉴에서 보고 싶은 지표만 자유롭게 켜고 끌 수 있습니다.
   - 활성화된 지표 수에 맞추어 위젯의 너비와 높이가 부드러운 애니메이션과 함께 최적으로 자동 조절됩니다.
9. **편리한 UI & 컨트롤**:
   - **진짜 반투명 알파 글래스**: 다른 앱 창(브라우저, 에디터 등) 위에 올려도 뒤의 내용이 훤히 비치는 48% 투과율 ↔ 완전 불투명 솔리드 원클릭 전환
   - **화면 최상단 밀착 (스냅 `⌘T`)**: 상단 메뉴바 바로 아래 1픽셀의 틈도 없이 자석처럼 부착
   - **자유로운 드래그 이동**: 위젯 어디든 마우스로 잡고 바탕화면 원하는 위치로 이동
   - **위치 및 설정 영속화**: 앱을 재실행해도 마지막 창 위치, 크기 모드, 언어, 활성화된 지표를 그대로 기억하여 복원
   - **항상 위 (Pin 📌)**: 버튼 하나로 다른 작업 창 위에 항상 띄우기 가능
   - **상단 메뉴바 통합**: 상단 메뉴바의 CPU 아이콘 클릭 시 위젯 열기/닫기, 3단계 모드 직접 선택(단축키 ⌘1, ⌘2, ⌘3), 지표 선택, 불투명 모드 토글(⌘O), 최상단 붙이기(⌘T), 자동 실행(⌘L)
   - **초경량 네이티브**: 백그라운드 CPU 및 메모리 점유율 극소화

10. **EN / KO 다국어 지원 (영문 기본값)**:
    - **영문(English) 모드가 기본값**으로 실행되며, 위젯 내 **`KO / EN` 버튼**이나 상단 메뉴바의 `Language` 메뉴에서 원클릭으로 한국어/영어를 자유롭게 전환할 수 있습니다.

## ⌨️ 단축키 안내

| 단축키 | 기능 |
| :--- | :--- |
| `⌘1` | 보통 크기 (Standard, 350x270) |
| `⌘2` | 작은 크기 (Compact, 320x125) |
| `⌘3` | 완전 한줄 (Minimal, 480x28 타이틀바 크기) |
| `⌘T` | 화면 최상단(메뉴바 바로 밑)으로 자석 스냅 |
| `⌘O` | 불투명 다크 ↔ 반투명 알파 글래스 토글 |
| `⌘L` | Mac 로그인 시 자동 실행 등록/해제 |
| `⌘M` | CGPU Monitor 위젯 열기 / 닫기 |
| `⌘Q` | 애플리케이션 종료 |

## 함께 제공되는 3가지 모니터링 솔루션

1. **iStat Menus 7 (기존 설치됨)**:
   - 바탕화면 우클릭 → `위젯 편집` → `iStat Menus` 위젯을 바탕화면이나 알림 센터에 추가
2. **오픈소스 eul & Stats (설치 완료)**:
   - `eul`: macOS 공식 WidgetKit 바탕화면/알림 센터 위젯 지원 (`open /Applications/eul.app`)
   - `stats`: 메뉴바 실시간 모니터링 최고 오픈소스 (`open /Applications/Stats.app`)
3. **CGPU Monitor (현재 프로젝트)**:
   - 바탕화면에 자유롭게 떠 있는 실시간 플로팅 데스크톱 위젯 (`open CGPUMonitor.app`)
